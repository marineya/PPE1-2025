Programmation et Projet Encadré 1

Mini Projet 1

Le projet 1 consistait à créer un programme qui permettait à partir d'un fichier contenant des URLs d'extraire des informations. Nous devions afficher la ligne de chaque url, leur lien, leur code http, leur encodage ainsi que leur nombre de mots. A partir de ce code, nous l'avions transformé en fichier HTML en ajoutant des balises HTML. Ainsi, nous obtenons un fichier HTML contenant le tableau avec les informations que nous avons sélectionné.
